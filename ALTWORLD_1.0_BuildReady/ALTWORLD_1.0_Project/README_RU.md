
# ALTWORLD — проект настольной grand strategy

Это полноценная исходная структура проекта, а не готовый установщик и не заявление о завершённой игре.
В текущей версии реализованы: игровой цикл, свободные приказы, адаптер локальной Ollama-модели,
контекстный исторический поиск через Wikipedia/Wikidata, память партии, сохранение/загрузка,
лента событий, базовые экономические и демографические показатели и интерактивная карта-схема.

## Требования
- Windows 10/11
- Node.js 20+
- Rust stable + Microsoft C++ Build Tools (для сборки Tauri)
- Ollama и модель `qwen3.5:4b` для локального ИИ (на этапе разработки)

## Запуск интерфейса
```powershell
npm install
npm run dev
```

## Запуск как desktop-приложение
```powershell
npm run tauri dev
```

## Сборка установщика
```powershell
npm run tauri build
```
Результат Tauri появится в `src-tauri/target/release/bundle/`.
Для Windows-сборки нужны Rust и системные зависимости Tauri.

## Локальная модель
По умолчанию приложение обращается к Ollama на `http://127.0.0.1:11434`.
Модель задаётся в настройках игры. Встроенная проверка соединения не скачивает модель автоматически.

## Веб-исследователь
Использует открытые API Wikipedia и Wikidata. Поиск выдаёт источники и выдержки, но не считает
любую найденную страницу доказанной истиной. Исторические сведения сохраняются отдельно от
альтернативных событий партии. Не вводите в поле приказов секретные данные.

## Архитектурный принцип
ИИ формирует предложения о ходе мира и последствиях приказов. Приложение проверяет структуру
изменений и не позволяет модели создавать неизвестные государства/объекты или удалять сущности
из-за ошибки формата. Это страховка целостности, а не замена ИИ жёстким симулятором.

## Ограничения текущей поставки
- Это первая интегрированная основа проекта; историческая карта пока представлена схематичной картой регионов.
- Для точных исторических границ потребуется подключить лицензированный набор геоданных с версиями по датам.
- Экономика и демография имеют начальные параметры и AI-обновления, но ещё не претендуют на историческую точность.
- Перед публичным релизом необходимо провести тестирование, аудит лицензий данных и упаковку модели/runtime.
