# Как получить Windows-установщик ALTWORLD

1. Создай на GitHub пустой репозиторий `ALTWORLD`.
2. В репозитории выбери **Add file → Upload files**.
3. Загрузи всё содержимое этой папки, включая скрытую папку `.github`.
   В корне репозитория должны лежать `package.json`, `index.html`, `src/`,
   `src-tauri/` и `.github/`, без дополнительной вложенной папки.
4. Нажми **Commit changes**.
5. Открой вкладку **Actions** и разреши запуск workflow, если GitHub спросит.
6. Дождись завершения `Build ALTWORLD for Windows`.
7. Открой успешный запуск и скачай `ALTWORLD-Windows-Installers` в разделе **Artifacts**.

В архиве Artifacts ожидаются установщики Windows `.exe` и `.msi`.

## Важно
- Это сборка текущей версии исходников, а не готовый релиз игры.
- Успешная компиляция не означает, что все игровые функции завершены или протестированы.
- Для ИИ на текущем этапе нужна Ollama на компьютере и модель `qwen3.5:4b`.
- Историческая карта пока схематическая, а не полноценная карта провинций.
- Если сборка упадёт, пришли скриншот или текст ошибки из GitHub Actions.
